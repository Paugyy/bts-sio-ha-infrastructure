## Adapter le lab

1. Ouvrir `generator/index.html`.
2. *Importer JSON* → `reference-infrastructure.json`.
3. Modifier adresses, VLAN, noms et ports.
4. Exporter les fichiers générés et la nouvelle configuration JSON.

La fiche [lab-reference.md](lab-reference.md) peut servir de modèle pour documenter votre propre variante.
