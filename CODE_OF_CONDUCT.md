# Code de conduite

## Engagement

Ce projet est un espace d'apprentissage. Chaque participant — étudiant, enseignant, professionnel — s'engage à rendre la collaboration respectueuse et constructive, quel que soit le niveau technique des autres.

## Comportements attendus

- Rester courtois, y compris dans les revues de code et les issues.
- Critiquer le travail, jamais la personne.
- Expliquer plutôt que juger : une question de débutant est légitime.
- Citer ses sources et respecter les licences.
- Ne jamais publier de données personnelles ou d'informations d'accès d'autrui.

## Comportements inacceptables

- Propos insultants, discriminatoires ou harcèlement.
- Publication d'informations privées sans consentement.
- Tentative d'accès non autorisé à une infrastructure décrite ici.
- Toute conduite inappropriée dans un cadre scolaire ou professionnel.

## Application

Les mainteneurs peuvent modifier ou supprimer des contributions non conformes et, si nécessaire, exclure un participant. Les signalements se font via un canal privé (voir [SECURITY.md](SECURITY.md#signaler-un-problème-de-sécurité)) et sont traités de manière confidentielle.
